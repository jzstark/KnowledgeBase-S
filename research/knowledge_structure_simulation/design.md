# 内容无关的知识结构模拟：实验设计

状态：初始设计记录。最小实现和运行结果已完成，实际算法、参数来源与范围以 [README.md](README.md)、[scenarios.json](scenarios.json) 为准。这里未引用来源的参数范围是情景假设，不是生产系统校准值。

## 目的与边界

比较平铺文章、平铺摘要和多层索引在相同信息找回率下的访问成本。无需真实文章、自然语言查询或在线模型。实验评估一个结构设计的条件性收益，不估计真实问答准确率、生产延迟或实际 API 费用。

当前运行数据没有 index；多层 index 的结果必须标作设计模拟。article/summary/entity 已存在，但未经实测校准的模拟也不能宣称是这些组件的生产成绩。

## 随机世界

每个合成查询对应一个相关性向量 R，R_i=1 表示文章 i 包含所需证据。第一版评估相关文章召回，不声称覆盖多证据推理或答案质量。

- 无聚集情景：R_i ~ Bernoulli(p)，彼此独立。
- 聚集情景：每个主题簇先生成 theta_j ~ Beta(alpha,beta)，再在簇内生成 R_i ~ Bernoulli(theta_j)。令 alpha=p*(1/rho-1)，beta=(1-p)*(1/rho-1)，得到边际相关率 p、簇内相关系数 rho；rho=0 单独使用独立模型。rho 不取 1。
- 用与当前查询标签无关的层级组织主题簇；随机打乱一定比例的文章归属，作为错误分组压力测试。禁止按当前查询的 R 临时构造完美索引。
- p 是工作负载稀疏度，不是可从文献查得的普适常数。零相关文章的试验单独报告空结果与无效访问成本，不丢弃或把 recall 设为 1 混入主结果。

## 可观察信号与隐藏真值

模拟器掌握 R，检索策略不能读取 R。读取原文后才确认文章相关性；第一版假设该确认无误。

平铺检索需要有信息的排序信号，不能只用随机读文章作为唯一基线。例如用 score_i=delta*R_i+epsilon_i、epsilon_i~Normal(0,1) 生成带噪声分数；delta 是待扫描的区分能力，非真实 BM25/embedding 的测量值。

摘要或 index 的可观察信号可先建模为带噪声的分组检测：目标为后代是否至少有一篇相关文档，信号具有真阳性率 s 与假阳性率 f。这是摘要能力的抽象假设，不是已证明的实现性质。它只提供候选导航，摘要命中本身不计入原文证据召回。

各方法共用同一世界和预先生成的信号；重复访问不重新抽签。平铺摘要与层级检索使用完全相同的摘要信号。分别测试逐层独立失误和跨层相关失误。不能对任意大组固定“同样便宜且同样准确”：组大小、层数变化时同时扫描检测退化与读取成本。

## 对照方法

1. 随机顺序读取原文：解析校验用的弱基线，不能作为唯一 CV 对照。
2. 带噪声排序的平铺原文检索：主要基线。
3. 同样摘要全部平铺、全局选择候选，再读取原文：隔离摘要贡献。
4. 同样摘要与父子关系，按信号选择分支并下钻：隔离层级贡献。

层级深度为 0 时退化为平铺。完美信号只用作理想上界。随机分组、无信息信号、强平铺检索器、高漏报率、高误报率必须出现在报告中。entity 图扩展留到第二版，以免把多个机制混在同一收益数字中。

## 成本与指标

分别记录：原文读取量、摘要/index 读取量、评分次数、一次性构建成本。统一用参数化工作单位计价，不把 Python 运行秒数称为系统检索延迟，也不直接换算成 token 或货币。

主结果为固定预算下的平均相关文章召回曲线；由预先确定的预算网格得到达到目标平均召回（例如 90%）所需的最小测试预算。没有达到目标就标记未达标，不只统计成功试验。不能让实际策略用隐藏 R 决定何时停止；目标召回只由评估器离线计算。

在双方都达到同一目标召回时，报告 1-C_structure/C_flat。报告配对成本差、召回差及蒙特卡洛标准误；其不确定性只描述固定模型下的随机误差，不覆盖模型失真。

另外列出构建成本，按 C_total(Q)=C_build+Q*C_query 给出摊销结果。若查询成本不下降，则没有正的摊销盈亏平衡点。不同工作单位的成本不能未经校准直接相加。

## 两阶段解析校验（自行推导）

假设 N 篇独立文章、每组 g 篇、N 可被 g 整除、每篇相关概率 p。所有组都先读一个摘要；检测阳性就读该组全部原文。摘要成本 c_s，原文成本 c_a，检测真阳性率 s，假阳性率 f：

```text
q = 1 - (1-p)^g
E[C] = (N/g)*c_s + N*(q*s + (1-q)*f)*c_a
```

每篇相关文章被找回的概率是 s；在存在相关文章的试验中，期望 recall 为 s。该公式仅校验上述两阶段策略，不是对带排名基线或真实系统的性能证明。s=1、f=0 为理想上界；s=f 时检测没有相关性区分能力。

唯一祖先路径且各层条件保留率为 s_l 时，相关文章路径保留概率为各层 s_l 的乘积。例如每层 0.95、三层得到 0.857375，尚未计入最终文章选择的损失。这说明层级变深可能降低召回；该算式不是生产测量。

## 情景与可复现性

实现时先固定扫描配置再看结果，避免挑选最有利的参数。采用小型核心网格加单因素压力测试，避免所有变量完全交叉造成组合爆炸。

初始候选的 N、p 范围已在实现时替换为 BEIR 统计锚点（见 parameter_sources.md）；它们仍不是本系统真实分布。rho、TPR/FPR、排序区分能力等未校准参数按预设情景扫描。跨情景统计只描述该预设网格，不当作真实世界平均收益。

保存种子、配置、逐次结果、解析校验与汇总图。先做小规模运行检查蒙特卡洛误差与运行时间，再确定重复数；同一试验的所有方法配对比较。
