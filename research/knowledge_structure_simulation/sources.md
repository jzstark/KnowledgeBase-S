# 知识结构离线模拟：建模依据与边界

查阅日期：2026-10-14。目标是设计不依赖具体文章与自然语言问题的、可重复的结构模拟；本文件记录文献与方案，尚无实验结果。

## 结论

可以做概率模拟，但不能从文献查到适用于任意知识库的“每篇文章有 0.08% 概率相关”。概率检索建模的是查询与文档条件下的相关性；脱离具体内容后，相关率、相关性聚集程度和路由误差必须作为公开的场景参数。模拟可以支持“在给定场景范围内，达到某召回率所需的读取成本降低多少”，不能直接证明运营系统问答准确率提高多少。

## 建议的最小模型

以下公式和参数组合是本实验方案推导，不是上述论文对本系统的测量结论。

1. **独立零模型。** 每个叶节点代表可验证证据单元，`R_i ~ Bernoulli(p)`；所有方法面对同一份隐藏真值。若不建模任何可观测相关信号，目录仅仅重排文章不会产生收益。若目录能提供有信息的群组检测，即使叶节点独立也可能获益，因此必须分别控制“聚集程度”和“检测质量”。
2. **聚集模型。** 每个主题簇取 `theta_g ~ Beta(alpha, beta)`，簇内 `R_i | theta_g ~ Bernoulli(theta_g)`。令 `alpha = p*(1/rho-1)`、`beta = (1-p)*(1/rho-1)`，则边际相关率为 `p`，同簇相关系数为 `rho`；`rho=0` 单独用独立模型。它表达“相关证据集中在少数主题”，不声称是真实知识库分布。
3. **有噪声路由。** 父节点真值为“后代至少含一个目标”，摘要/目录观测有独立指定的真阳性率 `s` 和假阳性率 `f`。筛选器只能访问观测，不能读取隐藏真值。单一路径、逐层条件保留率均为 `s` 时，深度 `d` 的路径保留概率是 `s^d`；有重叠路径、重试或相关误差时应由模拟计算，不能套用该式。
4. **读取成本。** 正文读取单位成本为 1，摘要成本为 `c`，目录检查成本为 `c_index`。被读过但未返回的节点也计费。以读取成本为指标时，不能改称墙钟时间或真实 token 节省。构建/更新成本单列，可另算查询次数的摊销阈值。

对于完全独立、均匀抽样的扫描，读 `m` 篇至少命中一次的概率为 `1-(1-p)^m`。这个式子只适用于无额外检索信号的模型；真实平铺检索通常会排序，不能把此式作为 BM25 或向量检索的表现。

## 公平比较与报告

- 最少保留：均匀扫描的分析参考线、有噪声排名的平铺检索、平铺摘要筛选、多层摘要/目录路由。平铺排名的质量也必须变化，不能只选随机扫描作为成绩基线。
- 固定相同证据真值、可访问的信息规则与成本单位；所有方法用配对随机场景。摘要生成或目录归属不能使用查询时的相关性标签，否则把答案提前交给了结构。
- 主指标用“固定预算召回率”，辅助指标用“达到目标召回率的成本”。未达到目标的运行必须报告失败比例，不能只平均成功运行；零相关文档的场景单列，不默认为 100% 召回。
- 扫描稀疏程度、聚集程度、摘要成本、漏检/误报率、树深和基线排序质量。至少保留无信号路由、低质量摘要、强平铺基线等可能失败的条件。
- 今天可先从少量预先固定的场景开始，再作敏感性分析。重复次数按 Monte Carlo 标准误确定；配对增益的标准误是逐次差值标准差除以重复次数平方根。它仅表示在固定模型下的数值精度。
- CV 的合适口径是“构建可复现的概率模拟，在明确的稀疏度与路由误差范围内，相同召回率下读取成本降低 X%”。数字须由最终代码生成，并附条件；不写成已上线系统实测效果。当前不存在 index 的部署事实不妨碍模拟设计，但模拟层级必须标为拟议设计。
